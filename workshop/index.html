Workshop 作坊

Things built in the gaps: a maths guide for the next cohort, a travel-story studio born at a hackathon, a cursor that jumps between screens, bridges that let AI agents hand work to each other — most of them made so that someone else could move faster.

Fig. 10 — A year of commits drawn as a walk; each shipped project an absorbing target.

The record

Most of what gets built between the bigger things is built for someone else: a guide for the next cohort, a map for incoming students, a template for fellow applicants, a bridge so that one AI can hand work to another.

The oldest still-used piece is the Tianjin maths guide, from 2023. The loudest is SocialOS: 1,222 commits in five days, most of them made by an orchestrated agent factory. The most visual is London Cuts, a travel-story studio with three visual moods that grew from a hackathon weekend.

In between: a cursor that jumps between screens, a fix for a browser that went deaf, seven dead ends and a working keyboard shortcut, an always-on agent host that taught its lessons and was then honestly uninstalled. The contribution lattice above is fetched live from GitHub at build time.

On GitHub since December 2021

The GitHub account dates from 1 December 2021. For three years it was quiet — coursework, a maths guide, a template — and then, in 2026, it erupted: most of the repositories were created that year, along with nearly all of the contributions, including a two-day spike when an automated agent factory built a hackathon product. The live counts on this page are fetched from GitHub at build time. Company work in private repositories is not counted, so the graph is a lower bound, not the whole output.

The Tianjin University maths guide

Instead of only using the curriculum, write a guide to it for everyone who comes after. Built from July 2023, the Tianjin University maths undergraduate guide gathers what a student needs — a foreword, the professional courses, the majors and how to contribute — first as a quick guide with a document library, then as a MkDocs site. It has been served at zhouyixiaoxiao.info since December 2025 and is the oldest thing on this page that other people still use.

TJU_Draw: shapes you can drag and rotate

A Windows drawing application written in C++ with MFC for the Tianjin University School of Mathematics computer practicum: draw lines, circles, ellipses, squares, rectangles and triangles, change stroke and fill colours, then drag, scale and rotate the shapes to any angle. The earliest interactive graphics in this collection — the plate on the home page is a distant descendant.

A Tianjin University letterhead in LaTeX

A bilingual XeLaTeX template that reproduces Tianjin University's letterhead style — TJU blue, a logo slot, a contact block — written during the PhD application season for reference letters, then published so that anyone else applying could use it too. It was announced on LinkedIn twenty-five minutes after the repository was created.

An always-on agent host, and an honest uninstall

A spare laptop became an always-on host for an open-source autonomous agent framework, driven from a phone through ordinary chat apps to run coding and browser tasks, with multi-agent channels, scheduled digests and an automated development loop for the SocialOS codebase. About two months of real use surfaced where autonomous agents break today: authentication churn, reliability when nobody is watching, and permissions that sprawl. The whole setup was uninstalled in July 2026 — the experiment was the point.

Took part in the week-long UK AI Agent Hackathon EP4, which opened on 1 March 2026 at Imperial College London — and shared the call with the SEMT PhD community the day before. The entry was SocialOS, submitted to five bounty tracks at once; the public repository keeps the pitch pack, the architecture and the evidence documents.

SocialOS: 1,222 commits in five days

SocialOS turns raw notes, voice memos, screenshots and encounters into structured memory about people and events, ‘self-mirror’ reflections and drafts for each platform, delivered through a publishing queue that a human approves. It runs only on the local machine. It was built for the UK AI Agent Hack in five days, with 1,222 commits between 5 and 9 March 2026 — 1,084 of them carrying an ‘[autodev]’ prefix from the automated agent factory orchestrated for the week. The public repository keeps the pitch pack and the evidence.

A public, sanitised collection of reusable skills and setup kits for coding agents — mail access, security-minded skills and a portable configuration template — plus small utilities for AI desktop apps. The larger personal library stays private; what is published is what anyone can safely reuse.

Why the browser's voice input went deaf

A bilingual repository that diagnosed why voice input failed in the ChatGPT Atlas browser — it stored its own audio-input priority and preferred an external monitor's microphone over the built-in one — and ships an audit script and a reversible fix that reorders the priority, plus a userscript that keeps video speed controls on ordinary sites.

A route site for a snowy Iceland drive

In April 2026, a self-drive around Iceland's ring road, along the south coast and through the East Fjords to Akureyri, with a stop in Oslo. For one snowy leg — Bakkagerði to Akureyri by Route 94, Mývatn, Húsavík and Goðafoss — a public Chinese route-decision site laid out A, B and C options with links to the official road conditions. Planning a trip like a product, again.

Global HackTour London: one city, three cuts

At the in-person Global HackTour London at UCL on 18–19 April 2026, built ‘London Cuts — One City, Three Cuts’: upload a London memory and get back a story in three narrative modes — Punk, Fashion, Cinema — along with a collectible postcard and a pin on a story atlas. The weekend prototype became the London Cuts product.

London Cuts

A creator tool for documenting a single-place trip with photos grounded in their own metadata, written stories and AI-generated postcards in six styles, switchable between three visual modes — Fashion, Punk and Cinema — with public reader pages, a map atlas and PDF or PNG export. The live demo tells ‘A Year Around London’ in thirteen stops and ‘A Week in Reykjavík’, and it has entry points for AI agents too: an llms.txt, an OpenAPI description and an MCP endpoint. London Cuts is a working name.

A fashion-editorial housing map

A single-page map for incoming Chinese LLM students at Bristol: seventeen student housing options within about a twenty-minute walk of the Law School, each tagged by how its information was sourced — verified, provider, search or live — with an application section, a mobile detail panel and an offline basemap fallback. Built in a weekend, with an editorial look borrowed from fashion magazines.

CatchMouse, rebuilt for Apple Silicon

A clean Swift rewrite of CatchMouse, an Intel-only utility from 2011: a menu-bar agent that warps the cursor to the left, centre or right display with global hotkeys, cycles between displays, remembers custom hotkeys per monitor, flashes display numbers and offers command-line verbs. It builds a universal app with only the command-line tools and needs no accessibility permission. MIT-licensed.

Seven dead ends and a working ⌘T

A small Swift helper, about 200 lines, that registers ⌘T only while the ChatGPT Atlas browser is in front and routes it to Claude — switching to an existing tab, duplicating it or opening a new one — through the accessibility interface. The README is the fun part: it documents why seven standard approaches fail, because the browser's new-tab page is a native view rather than a web page.

Pro Agent Bridge

A local MCP server that turns ChatGPT's developer mode into a bounded coding and hand-off surface for one repository: reading files, searching, exact edits, git inspection and safe verification commands. It extends the MIT-licensed open-source CodexPro by rebel0789 with hand-off from ChatGPT Pro to Claude Code, saved-session capture and hardened polling, and it is still in daily use. Credit where it is due: the foundation is upstream.

A legal-career roadmap for Bristol LLM students

A responsive, editorial-style Chinese guide for Bristol LLM students planning a legal career back in China in 2026–27: chapter navigation, full-text search, filterable events and recruitment, a four-week practice plan, ten copy-ready templates, dated updates on official AI products and 42 primary sources — with no analytics and no backend. The same editorial language as the housing map: a small shelf of Bristol guides.
