作坊 Workshop

见缝插针造出来的东西：留给下一届的数学指北、黑客松里诞生的旅行故事工作室、在屏幕之间跳跃的光标、让 AI 智能体互相交接工作的桥——大多是为了让别人走得更快。

图 10 — 一年的提交画成一条游走路径，每个上线的项目都是一个吸收点。

记录

在大事之间见缝插针造出来的东西，多半是为别人而造：给下一届的指南，给新生的地图，给同批申请者的模板，一座让一个 AI 能把活交给另一个 AI 的桥。

最早、且至今仍有人用的，是 2023 年的天大数学指北。动静最大的，是 SocialOS：五天 1,222 次提交，大部分出自一座编排好的智能体工厂。最好看的，是 London Cuts——一个有三种视觉情绪的旅行故事工作室，起于一个黑客松周末。

其间还有：一个在屏幕之间跳跃的光标，一个修好「聋掉」的浏览器的补丁，七条死路和一个终于能用的快捷键，一台教会了一些道理、然后被坦然卸载的 7×24 智能体主机。上方的贡献格点，在构建时从 GitHub 实时获取。

2021 年 12 月起的 GitHub

GitHub 账号注册于 2021 年 12 月 1 日。前三年很安静——课程作业、一份数学指北、一个模板——然后在 2026 年喷薄而出：大部分仓库都建于这一年，几乎全部的贡献也是；其中有一个两天的尖峰，是一座自动化的智能体「开发工厂」在黑客松上搭建产品时留下的。本页的实时数字，在构建时从 GitHub 获取。公司私有仓库里的工作不计在内，所以这张图是下限，不是全部。

天津大学数学学院本科生指北

不只是「读」完课程，而是把它写成一份指南，留给后来的每一个人。2023 年 7 月起动手搭建的《天津大学数学学院本科生指北》，汇集了一个学生需要知道的东西——前言、专业课、各个专业方向，以及如何参与贡献——先是一份附资料库的快速指南，后来成了一个 MkDocs 站点。自 2025 年 12 月起部署在 zhouyixiaoxiao.info，它是这一页上最早、而且至今仍被别人使用的作品。

TJU_Draw：可以拖拽与旋转的图形

为天津大学数学学院计算机实习写的 Windows 绘图程序，用 C++ 与 MFC 实现：可以画直线、圆、椭圆、正方形、长方形和三角形，修改描边与填充颜色，再对图形进行拖拽、缩放和任意角度的旋转。这是这批作品里最早的交互图形——首页那块底片，算是它的远房后代。

天津大学公函版式的 LaTeX 模板

一个中英双语的 XeLaTeX 模板，复刻天津大学的公函版式——天大蓝、校徽位、联系信息栏——写于博士申请季，本是为推荐信准备的，随后公开出来，让其他申请者也能直接用。仓库建好二十五分钟后，就在领英上宣布了。

一台 7×24 在线的智能体主机，以及一次坦然的卸载

把一台闲置笔记本改成一台 7×24 在线的主机，跑一套开源的自治智能体框架：用手机在普通聊天软件里就能遥控它，执行编程和浏览器任务；配有多智能体频道、定时简报，还有一个为 SocialOS 代码库服务的自动开发循环。大约两个月的真实使用，摸清了自治智能体今天会在哪里失灵：认证反复失效、无人值守时的可靠性、不断蔓延的权限。2026 年 7 月，整套系统被卸载——这场实验本身，就是目的。

帝国理工 UK AI Agent Hack

SocialOS：五天，1,222 次提交

SocialOS 把零散的笔记、语音备忘、截图和见面记录，变成关于人和事件的结构化记忆、「自我镜像」式的反思，以及适配各个平台的草稿，再经由一个由人审批的发布队列交付；它只在本机运行。它为 UK AI Agent Hack 而做，五天里——2026 年 3 月 5 日至 9 日——共 1,222 次提交，其中 1,084 次带着「[autodev]」前缀，出自那一周编排好的自动化智能体工厂。公开仓库保留着路演材料与证据。

浏览器的语音输入为什么「聋」了

一个中英双语仓库：查明 ChatGPT Atlas 浏览器语音输入失灵的原因——它自己存了一份音频输入优先级，把外接显示器的麦克风排在了内置麦克风之前——并提供审计脚本和可回滚的修复，重新排列优先级；另附一个用户脚本，让普通网站保留视频倍速控制。

Global HackTour 伦敦站：一座城，三种剪辑

2026 年 4 月 18–19 日，在伦敦大学学院举办的 Global HackTour 伦敦站线下黑客松上，做出了「London Cuts——一座城，三种剪辑」：上传一段伦敦记忆，就能得到三种叙事模式——朋克、时装、电影——的故事，外加一张可收藏的明信片，和故事地图上的一枚图钉。这个周末原型，后来长成了 London Cuts 产品。

London Cuts 旅行故事工作室

一个创作工具，用来记录一次「只去一个地方」的旅行：照片的时间与位置取自照片本身的元数据，配上文字故事，以及六种风格的 AI 明信片；整体可以在三种视觉模式——时装、朋克、电影——之间切换，有公开阅读页、地图集和 PDF / PNG 导出。在线演示讲述了 13 站的《A Year Around London》和《A Week in Reykjavík》，还为 AI 智能体准备了入口：llms.txt、OpenAPI 描述和一个 MCP 端点。London Cuts 是暂定名。

时装杂志风的租房地图

一张写给来布里斯托读法学硕士的中国学生的单页地图：法学院步行约二十分钟范围内的 17 处学生住宿，每一条都标明信息来源的可信度——核实、房东、搜索或实时——并附申请指南、移动端详情面板和离线底图兜底。一个周末做完，版式借了时装杂志的气质。

为 Apple Silicon 重写的 CatchMouse

对 2011 年那个只支持 Intel 的小工具 CatchMouse 的一次 Swift 彻底重写：常驻菜单栏，用全局快捷键把光标瞬移到左、中、右任一块显示器，可以循环切换，按显示器记住自定义快捷键，能闪显屏幕编号，还提供命令行指令。只用命令行工具就能构建出通用应用，也不需要辅助功能权限。MIT 许可。

七条死路与一个能用的 ⌘T

一个约 200 行的 Swift 小工具：只在 ChatGPT Atlas 浏览器位于前台时注册 ⌘T，通过辅助功能接口把它导向 Claude——切到已有的标签、复制它，或者新开一个。README 才是最有意思的部分：它记录了七种常规方案为什么都行不通——因为这款浏览器的新标签页是原生视图，而不是网页。

Pro Agent Bridge 智能体桥

一个本地 MCP 服务器，把 ChatGPT 的开发者模式变成针对单个仓库、有边界的编程与交接界面：读文件、搜索、精确编辑、查看 git、运行安全的验证命令。它在 rebel0789 以 MIT 许可开源的 CodexPro 基础上扩展，加入了从 ChatGPT Pro 到 Claude Code 的交接、会话保存与加固的轮询，至今仍在日常使用。饮水思源：地基来自上游。

给布里斯托法学硕士的法律职业路线图

一份响应式、编辑风的中文指南，服务打算回国发展法律职业的布里斯托法学硕士（2026–27）：分章导航、全文检索、可筛选的活动与招聘信息、四周实务训练计划、十份可直接复制的模板、若干带日期的官方 AI 产品动态，以及 42 条一手来源——不做统计追踪，也没有后端。和租房地图同一种编辑语言：一小排「布里斯托指南」书架。
